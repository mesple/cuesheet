# Cue Sheet 版面規範

最後更新：2026-11-08（加訂閱框）

> 電子報與網站是同一份刊物，版面以 **2026 年 10 月號試刊** 為準。本檔是唯一依據；
> 要改字型、字級、顏色、圖片尺寸或欄序，先改本檔並經編輯同意，再改程式。

## 一、規範放在哪裡

| 對象 | 依據 | 怎麼產生 |
| --- | --- | --- |
| 電子報（深度聆聽版、配樂新訊版） | 本檔第三節 | `python tools/build_newsletter.py <期別>`：讀 `issues/<期別>.json` 與 `items/*.json`，版型寫在程式裡，**不手排 HTML** |
| 電子報空白版型（看格式用） | 本檔第三節 | `python tools/build_newsletter.py --template`，輸出 `templates/cue_sheet_template_collector.html`、`templates/cue_sheet_template_news.html` |
| 網站各頁 | 本檔第四節 | `python build_items.py`（單則頁、分類頁、作曲家頁、首頁），`python build_pages.py`（首頁、電子報列表） |
| 近期國內電影音樂活動 | 本檔第三節第 11 欄、README | `build_section.py`（電子報欄）、`event/index.html`（線上活動頁） |

### 共通規則

- 播放鍵一律用 CSS 畫的三角形，不用「▶」「►」（Gmail 會換成 emoji）。
- 每張圖下方標「圖片來源：○○」；Spotify 封面寫「圖片來源：Spotify」。
- 不直接引用來源網站的圖片網址；封面優先用 Spotify 官方封面（版本一致時），其他圖片放 GitHub `images/YYYY-MM/`。
- 中文之間不空格，中英文之間空一格。

### 欄序

- 深度聆聽版：本期專題 → 重磅點評 → 唱片架 → 精選試聽 → 作曲家專訪 → 週末cue一下 → 訂閱框 → 頁尾
- 配樂新訊版：本期專題 → 快訊 → 社群雷達 → 歐亞觀察 → In memoriam → 近期國內電影音樂活動 → 訂閱框 → 頁尾

## 五、資料欄位（產生器讀的欄位）

`items/<期別>.json` 每則：

| 欄位 | 用途 |
| --- | --- |
| `id`、`issue`、`type`、`date`、`region` | 代號、期別、類型（新聞／樂評／發行／訪談／試聽／訃聞／社群）、日期、地區（只給後台排序） |
| `title`、`byline` | 標題、作曲家（樂評、唱片架、試聽的作曲家另起一行） |
| `summary` | 短摘要：網站列表用；唱片架寫「廠牌｜說明」 |
| `body` | 長文（Markdown，可用 `##` 小標、`-` 清單、`|` 表格）：電子報樂評、專訪、專題用這欄；沒有就用 summary |
| `teaser` | 訪談列表約 50 字 |
| `media` | 圖或影片：`{kind:image,url,caption,credit,credit_url,link,hosting}`、`{kind:youtube,id,caption（上傳頻道名）}` |
| `sources`、`spotify`、`composers`、`related`、`web`、`internal_note` | 來源、Spotify 專輯、作曲家代號、相關則、上不上網站、編輯備註 |

`issues/<期別>.json`：`issue`、`edition`（collector／news）、`date`、`kicker`、`editor_note`、`feature`、`sections`（各欄放哪幾則；歐亞觀察另有 `list`＝其他歐亞動態，In memoriam 另有 `brief`＝同期辭世者）、`weekend`（`playlist_text`、`next`）、`sources_footer`、`cutoff`、`home_reviews`、`releases_first`、`events_pick`／`events_skip`。

## 六、每期流程

1. 收集、分類 → 寫進 `items/<期別>.json`、`issues/<期別>.json`。
2. `python tools/build_newsletter.py <期別>` → `out/cue_sheet_<期別>.html`（電子報版）與 `newsletter/<期別>/index.html`（網站版）；終端機會顯示大小。
3. 編輯審稿：改資料檔，再重跑第 2 步；不直接改 HTML。
4. `newsletter/issues.json` 加一筆 → `python build_items.py`、`python build_pages.py`。
5. 推上 GitHub，用 Chrome 檢查網站版圖片與影片 → 匯入 MailerLite、寄測試信 → 寄出。
